# cveta2 labels

Показывает метки (label) проекта CVAT и в терминале позволяет их добавить, переименовать, перекрасить и удалить. Нужна, когда в проекте появился новый класс или надо исправить имя метки.

> **Внимание.** Удаление метки нельзя отменить. CVAT удаляет вместе с меткой все аннотации с ней во всех задачах (task) проекта. Перед удалением прочитайте раздел [Удаление метки](#удаление-метки).

## Примеры

Напечатать метки проекта и выйти (работает без терминала):

```bash
cveta2 labels -p "Retail shelves" --list
```

Открыть меню редактирования меток проекта 123 (только в терминале):

```bash
cveta2 labels -p 123
```

Выбрать проект из списка, затем открыть меню:

```bash
cveta2 labels
```

## Синтаксис и аргументы

```text
cveta2 labels [-h] [--project PROJECT] [--list]
```

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--project`, `-p` | выбор в терминале | ID или имя проекта. Можно указать организацию: `my-team/Retail shelves`; `/Retail shelves` выбирает личное пространство. Без префикса организация берётся из конфигурации. |
| `--list` | выкл. | Напечатать метки проекта и выйти, ничего не меняя. |
| `-h`, `--help` | | Показать справку. |

## Как это работает

1. Команда подключается к CVAT и находит проект по `--project`. Без `--project` она показывает список проектов для выбора.
2. С `--list` она читает метки проекта, печатает их по алфавиту и завершается.
3. Без `--list` она открывает меню. Перед каждым шагом меню печатается текущий список меток. Пункты меню:
   - «Добавить метку»;
   - «Переименовать метку», «Изменить цвет метки», «Удалить метку» (только если в проекте есть метки);
   - «Готово».
4. Каждое изменение сразу отправляется в CVAT. После него команда заново читает метки из CVAT. Меню повторяется, пока вы не выберете «Готово» или не отмените выбор.

Изменения записываются только в CVAT. Локальные файлы и кэши команда не трогает.

### Добавление метки

Команда спрашивает имя новой метки. Пустой ввод отменяет шаг. Если метка с таким именем уже есть (регистр букв не важен), команда печатает предупреждение и ничего не меняет. Цвет новой метке назначает CVAT.

### Переименование метки

Вы выбираете метку из списка и вводите новое имя. Пустой ввод отменяет шаг. Имя, которое уже занято другой меткой (регистр не важен), не принимается. Если имя не изменилось, команда печатает `Имя не изменилось`. ID метки остаётся прежним, аннотации сохраняются. Подтверждение не спрашивается.

### Изменение цвета

Вы выбираете метку и вводите цвет в формате `#rrggbb`, например `#ff0000`. В вопросе показан текущий цвет. Пустой ввод отменяет шаг. Другой формат не принимается: команда просит ввести цвет снова. Цвет сохраняется в нижнем регистре. Подтверждение не спрашивается.

### Удаление метки

> **Внимание.** Удаление необратимо. Вместе с меткой CVAT удаляет все аннотации с ней во всех задачах проекта. cveta2 не умеет вернуть удалённую метку или её аннотации.

1. Вы отмечаете одну или несколько меток. Пустой выбор ничего не удаляет.
2. Команда читает аннотации всех задач проекта и считает для каждой выбранной метки фигуры (shapes), теги и треки. Для каждой метки печатается число аннотаций.
3. Если задачу прочитать не удалось, команда предупреждает, что точное число аннотаций неизвестно. Такой подсчёт считается неполным: число найденных аннотаций печатается как «не менее N», для метки без найденных аннотаций печатается «число аннотаций неизвестно», и удаление требует ввода имён меток.
4. Подтверждение зависит от результата:
   - есть аннотации или подсчёт неполный: команда печатает предупреждение и просит ввести имена выбранных меток через запятую. Набор введённых имён должен точно совпасть с выбранным (пробелы по краям не важны, регистр важен). Иначе удаление отменяется;
   - аннотаций нет и подсчёт полный: команда спрашивает «да/нет», по умолчанию «нет».
5. После подтверждения метки удаляются в CVAT одним запросом.

## Результат

Команда не создаёт файлов. Список меток выглядит так:

```text
Проект 'Retail shelves': 3 меток:
  - 'bottle' (id=40)  цвет=#a00000
  - 'can' (id=41)  цвет=#70a000
  - 'shelf' (id=42)  цвет=#d06080
```

Если у метки есть атрибуты, после цвета печатается `атрибуты: ...`. Проект без меток печатается как `Проект 'Retail shelves': нет меток`.

Сообщения меню:

```text
Метка 'box' добавлена
Метка 'can' → 'tin'
Цвет метки 'tin': #70a000 → #00ff00
Метка 'bottle' (id=40): 12 аннотаций будет УНИЧТОЖЕНО
ВНИМАНИЕ: удаление меток НЕОБРАТИМО уничтожит все аннотации (shapes), использующие эти метки!
Удалены метки: bottle
```

### Коды завершения

| Код | Когда |
|---|---|
| 0 | Метки напечатаны, или меню закрыто через «Готово» или отмену. Отказ от удаления тоже даёт 0. |
| 1 | Ошибка подключения, проект не найден, меню нужно, а терминала нет. |
| 2 | Неверные аргументы командной строки. |

## Интерактивный и неинтерактивный режим

Без `--project` команда просит выбрать проект. Без `--list` она открывает меню редактирования.

При `CVETA2_NO_INTERACTIVE=true` работает только `--list` вместе с `--project`. Без `--project` команда завершается с кодом 1 и сообщением `Interactive prompt required but CVETA2_NO_INTERACTIVE=true. Pass --project / -p to specify the project ID or name.` Редактировать метки без терминала нельзя: для этого есть функция [`cveta2.update_labels`](#из-python).

## Частые ошибки

```text
Interactive prompt required but CVETA2_NO_INTERACTIVE=true. Pass --list to view labels non-interactively.
```

Меню нельзя открыть без терминала. Добавьте `--list`, чтобы только посмотреть метки, или измените метки из Python.

```text
Введите цвет в формате #rrggbb (например, #ff0000)
```

Цвет введён не в формате `#rrggbb`. Введите шесть шестнадцатеричных цифр после `#`.

```text
Введённые имена не совпадают. Ожидалось: bottle, can. Удаление отменено.
```

Введённые имена не совпали с выбранными метками. Ничего не удалено. Запустите удаление снова и введите имена точно так, как они показаны.

```text
Не удалось прочитать аннотации задач [456]: точное число аннотаций выбранных меток неизвестно
```

CVAT не отдал аннотации задачи 456. Удаление всё равно возможно, но только через ввод имён меток. Лучше выяснить причину и повторить позже.

## Из Python

```python
cveta2.get_labels(project, *, connection=None) -> list[LabelInfo]
cveta2.update_labels(project, *, add=None, rename=None, delete=None, recolor=None, connection=None) -> None
```

- `get_labels` возвращает метки проекта. У каждой есть поля `id`, `name`, `color`, `attributes`.
- `update_labels` отправляет все изменения в CVAT одним запросом:
  - `add`: список имён новых меток;
  - `rename`: словарь `{ID метки: новое имя}`;
  - `recolor`: словарь `{ID метки: "#rrggbb"}`;
  - `delete`: список ID меток.

`update_labels` ничего не проверяет и не спрашивает: нет проверки занятых имён, подсчёта аннотаций и подтверждения. `delete` сразу и навсегда удаляет метки вместе с их аннотациями.

`project` — ID или имя проекта. Если проекта с таким именем нет, поднимается `cveta2.ProjectNotFoundError`. Несуществующий ID приводит к ошибке CVAT (HTTP 404). Ошибки CVAT поднимаются как `cveta2.CvatApiError`. Обе — подклассы `cveta2.Cveta2Error`.

```python
import cveta2

labels = cveta2.get_labels("Retail shelves")
ids = {label.name: label.id for label in labels}
cveta2.update_labels("Retail shelves", add=["box"], rename={ids["can"]: "tin"})
```

Параметр `connection` описан на странице [Python API](../python-api.md).
