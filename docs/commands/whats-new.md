# cveta2 whats-new

Показывает задачи (task) проекта, которые завершились в CVAT, но которых нет в вашей прошлой выгрузке. Нужна, чтобы решить, пора ли выгружать проект заново. Команда ничего не скачивает и не пишет.

## Примеры

Сравнить проект с прошлой полной выгрузкой:

```bash
cveta2 whats-new -p "Retail shelves" -d output/dataset.csv
```

То же по ID проекта:

```bash
cveta2 whats-new -p 123 -d output/dataset.csv
```

## Синтаксис и аргументы

```text
cveta2 whats-new [-h] [--project PROJECT] --dataset DATASET
```

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--project`, `-p` | выбор в терминале | Проект: ID, имя, `ORG/PROJECT` или `/PROJECT` (личное пространство), как у [fetch](fetch.md#как-выбирается-проект). |
| `--dataset`, `-d` | обязателен | Путь к `dataset.csv` прошлой выгрузки. |
| `-h`, `--help` | | Показать справку. |

## Как это работает

1. Команда читает `--dataset`. В файле должны быть столбцы `job_stage`, `job_state` и `task_id`. Это происходит до подключения к CVAT.
2. По файлу строится точка отсчёта whats-new ([what's-new baseline](../../GLOSSARY.md)):
   - известные задачи — завершённые задачи ([completed task](../../GLOSSARY.md)) из `dataset.csv`, а также из `obsolete.csv` и `deleted.csv`, если они лежат в той же папке. Из `in_progress.csv` в той же папке учитываются только задачи, у которых все строки имеют `task_completed=True`;
   - задача отсечки — наибольший `task_id` завершённой задачи в `dataset.csv`. Если завершённых задач в файле нет, берётся наибольший `task_id` вообще. Задача отсечки только печатается и на результат не влияет.
3. Команда читает список задач проекта в CVAT и оставляет задачи со статусом `completed`, которых нет среди известных. Задачи, которые при выгрузке были в работе и с тех пор завершились, тоже попадают в список. Дата изменения задачи не учитывается.
4. Список печатается по возрастанию ID.

Если рядом с `dataset.csv` нет остальных файлов полной выгрузки (например, вы скопировали только `dataset.csv`), задачи, которые попали только в `obsolete.csv` или `deleted.csv`, будут показаны как новые. Держите четыре файла вместе.

Список игнорируемых задач ([ignore list](../../GLOSSARY.md)) команда не учитывает.

## Результат

Файлы не пишутся. Вывод:

```text
Загружен output/dataset.csv: 30 строк
Задача отсечки (из output/dataset.csv): task_id=455
Проект 'Retail shelves': 2 задач(а) завершено после task_id=455:
id=456 shelves-batch-07 (updated 2026-11-20T11:33:27.641268+00:00)
id=457 shelves-batch-08 (updated 2026-11-20T11:40:02.118899+00:00)
```

Если новых задач нет:

```text
Новых завершённых задач в проекте 'Retail shelves' после task_id=455 не найдено
```

В строке со списком написано «после task_id=N», но в список попадают и задачи с меньшим ID, если их нет среди известных.

### Коды завершения

| Код | Значение |
|---|---|
| `0` | Проверка выполнена, есть новые задачи или нет. |
| `1` | Ошибка: файл не найден, нет нужных столбцов, пустой `task_id`, проект не найден, ошибка CVAT, нужен ввод в неинтерактивном режиме. |
| `2` | Неверные аргументы командной строки (например, нет `-d`). |

## Интерактивный и неинтерактивный режим

Без `-p` команда в терминале предлагает выбрать проект так же, как [fetch](fetch.md#интерактивный-и-неинтерактивный-режим). С `CVETA2_NO_INTERACTIVE=true` нужен `-p`. Без него команда всё равно подключается к CVAT и, если кэш списка проектов пуст, загружает список проектов, и только потом завершается с ошибкой.

## Частые ошибки

**`Ошибка: файл не найден: output/dataset.csv`**

Неверный путь в `-d`.

**`Ошибка: в output/dataset.csv отсутствуют обязательные столбцы: job_stage, job_state`**

Файл не из выгрузки cveta2 или из него удалены столбцы. Используйте `dataset.csv` из [fetch](fetch.md) или [fetch-task](fetch-task.md).

**`Ошибка: столбец task_id в output/dataset.csv пуст — невозможно определить задачу отсечки.`**

В файле нет строк или нет ни одного `task_id`.

**`Interactive prompt required but CVETA2_NO_INTERACTIVE=true. Pass --project / -p to specify the project ID or name.`**

В неинтерактивном режиме не указан `-p`.

**`Не удалось подключиться к CVAT (https://cvat.example.com): ...`**

CVAT недоступен или адрес в конфигурации неверный. Файл `-d` к этому моменту уже прочитан. Проверьте подключение командой [doctor](doctor.md).

## Из Python

```python
cveta2.whats_new(
    project: int | str,
    dataset: str | Path,
    *,
    connection: Connection | None = None,
) -> WhatsNewResult
```

Возвращает `WhatsNewResult` с полями `tasks` (список задач, у каждой есть `id`, `name`, `updated_date`) и `cutoff` (ID задачи отсечки). Ничего не печатает.

Исключения (подклассы `cveta2.Cveta2Error`): файл не найден, нет нужных столбцов, пустой `task_id`, проект не найден, ошибки CVAT.

```python
import cveta2

result = cveta2.whats_new("Retail shelves", "output/dataset.csv")
for task in result.tasks:
    print(task.id, task.name)
```

Как задать подключение — в [Python API](../python-api.md).
