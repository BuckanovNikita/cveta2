# cveta2 fetch-task

Выгружает bbox-аннотации только выбранных задач (task) проекта CVAT и скачивает их изображения. Это выгрузка задач ([task fetch](../../GLOSSARY.md)): она нужна, чтобы быстро получить одну или несколько задач без полной выгрузки проекта.

## Примеры

Выгрузить две задачи по ID; проект определяется по первой задаче:

```bash
cveta2 fetch-task -t 456 457 -o output/
```

Выгрузить задачу по имени, без изображений:

```bash
cveta2 fetch-task -p "Retail shelves" -t shelves-batch-07 -o output/ --no-images
```

Выгрузить задачи проекта из другой организации и заново скачать их аннотации с CVAT:

```bash
cveta2 fetch-task -p "my-team/Retail shelves" -t 456 457 -o output/ --force
```

## Синтаксис и аргументы

```text
cveta2 fetch-task [-h] [--project PROJECT] [--task [TASK ...]] --output-dir OUTPUT_DIR [--completed-only] [--no-images] [--images-dir IMAGES_DIR] [--save-tasks] [--no-cache] [--force]
```

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--project`, `-p` | по первой задаче | Проект: ID, имя, `ORG/PROJECT` или `/PROJECT` (личное пространство), как у [fetch](fetch.md#как-выбирается-проект). Если не указан, проект берётся из первого числового ID в `-t`. |
| `--task`, `-t` | выбор в терминале | ID или имена задач через пробел. `-t` без значений — выбор задач в терминале. |
| `--output-dir`, `-o` | обязателен | Каталог для `dataset.csv` и `deleted.csv`. Если его нет, он создаётся. |
| `--completed-only` | выкл. | Из выбранных задач выгружать только задачи со статусом `completed` в CVAT. |
| `--no-images` | выкл. | Не скачивать изображения из S3. |
| `--images-dir` | из конфигурации | Каталог для изображений на этот запуск. Важнее настроек конфигурации. |
| `--save-tasks` | выкл. | Записать CSV каждой задачи в `<output-dir>/.tasks/task_<id>.csv`. |
| `--no-cache` | выкл. | Не читать и не записывать кэш аннотаций. |
| `--force` | выкл. | Скачать аннотации выбранных задач заново с CVAT и обновить кэш аннотаций. |
| `-h`, `--help` | | Показать справку. |

### Как задачи сопоставляются с `-t`

- Число сначала ищется среди ID задач проекта, потом среди имён.
- Текст ищется среди имён задач проекта, регистр букв не важен.
- Если несколько задач проекта имеют одно имя, команда останавливается с ошибкой и перечисляет их ID.
- Одна и та же задача, указанная дважды, выгружается один раз.
- Задача из списка игнорируемых задач ([ignore list](../../GLOSSARY.md)) не выгружается: команда печатает предупреждение о пропуске (если у задачи в списке не стоит `silent`) и затем ошибку `Task not found`.

## Как это работает

1. Проект берётся из `-p`. Без `-p` команда читает первую задачу из `-t`, у которой значение — число, и берёт её проект. Если чисел в `-t` нет, проект выбирается в терминале.
2. Команда находит задачи из `-t` в проекте. С `--completed-only` из них остаются задачи со статусом `completed`.
3. Аннотации задач читаются так же, как у [fetch](fetch.md#как-это-работает): из кэша аннотаций ([annotation cache](../../GLOSSARY.md)) или с CVAT, только прямоугольники и полигоны (полигон заменяется описанным прямоугольником); фигуры других типов пропускаются с предупреждением. Ошибки CVAT обрабатываются так же, как у `fetch`: задача с ошибкой 5xx пропускается с сообщением `Ошибка CVAT (HTTP <код>), задача #<id> '<имя>' пропущена`, и выгрузка завершается с кодом 0. С `CVETA2_RAISE_ON_FAILURE=true` такая ошибка останавливает команду с кодом 1. Ограничение частоты запросов (HTTP 429) всегда останавливает команду.
4. С `--save-tasks` CSV каждой непустой задачи записывается в `.tasks/`.
5. Если изображения не отключены, команда скачивает изображения этих задач в кэш изображений ([image cache](../../GLOSSARY.md)). Уже скачанные файлы пропускаются. Каталог выбирается так же, как у `fetch` (см. [Кэш изображений](../images-and-cache.md#кэш-изображений)).
6. Записываются `dataset.csv` и `deleted.csv`. Строки не раскладываются по четырём файлам, как при полной выгрузке; что попадает в эти файлы — в [Формат данных](../dataset-format.md#выгрузка-задач).

В отличие от `fetch`, команда:

- не спрашивает про существующую папку `-o` и всегда пишет в неё поверх;
- не удаляет из кэша аннотаций записи других задач;
- не имеет флагов `--raw` и `--skip-validation`.

## Результат

| Файл | Когда |
|---|---|
| `dataset.csv`, `deleted.csv` | всегда |
| `.tasks/task_<id>.csv` | с `--save-tasks`, для задач с аннотациями |

Другие файлы в папке `-o` не трогаются.

Пример вывода:

```text
Проект определён по задаче 'shelves-batch-07' (id=456): project_id=123
Команда для повторного запуска:
cveta2 fetch-task -p 'Retail shelves' -t 456 457 -o output/
Отбор задач: 2 к загрузке; прошло 0.5 с
Изображения: 0 загружено, 8 из кэша, 0 ошибок (всего 8); прошло 0.0 с
Dataset CSV saved to output/dataset.csv (8 images, 45 rows)
Deleted CSV saved to output/deleted.csv (0 images, 0 rows)
Выгрузка завершена: прошло 0.8 с
```

Строка `Команда для повторного запуска:` печатается, если проект не был указан в `-p` или задачи не были указаны в `-t`.

### Коды завершения

| Код | Значение |
|---|---|
| `0` | Выгрузка завершена. |
| `1` | Ошибка: задача или проект не найдены, имя задачи неоднозначно, не настроен каталог изображений, ошибка CVAT или S3, нужен ввод в неинтерактивном режиме. |
| `2` | Неверные аргументы командной строки (например, нет `-o`). |

## Интерактивный и неинтерактивный режим

В терминале команда спрашивает:

- проект, если нет `-p` и в `-t` нет числового ID. Выбор устроен так же, как у [fetch](fetch.md#интерактивный-и-неинтерактивный-режим);
- задачи, если `-t` не указан или указан без значений. Показываются задачи проекта, кроме игнорируемых; можно выбрать несколько;
- каталог изображений, если он не настроен и нет `--images-dir` и `--no-images`. Ответ сохраняется в личную конфигурацию.

С `CVETA2_NO_INTERACTIVE=true` нужны `-t` со значениями, `-p` (или числовой ID в `-t`) и `--images-dir`, `--no-images` или настроенный каталог изображений.

## Частые ошибки

**`Task not found: '9999'. Available tasks: 'shelves-batch-08' (id=457), 'shelves-batch-07' (id=456), ...`**

Задачи нет в проекте, или она в списке игнорируемых задач. Проверьте ID и `cveta2 ignore --list`.

**`CVAT: операция get_task, GET <адрес>/api/tasks/9999; HTTP 404; ... detail: No Task matches the given query.`**

Проект не указан в `-p`, а первой задачи из `-t` нет в CVAT, поэтому проект определить не удалось. Проверьте ID задачи или добавьте `-p`.

**`Имя задачи 'shelves-batch-07' неоднозначно: 'shelves-batch-07' (id=456), 'shelves-batch-07' (id=458). Укажите числовой ID задачи.`**

В проекте несколько задач с этим именем. Укажите ID.

**`Interactive prompt required but CVETA2_NO_INTERACTIVE=true. Pass task ID(s) or name(s) with --task / -t to specify task(s).`**

В неинтерактивном режиме указан `-p`, но не указан `-t`.

**`Interactive prompt required but CVETA2_NO_INTERACTIVE=true. Pass --project / -p to specify the project ID or name.`**

Не указан `-p`, а в `-t` нет числового ID (только имена или `-t` не задан). По имени задачи проект не определить: добавьте `-p`.

**`Задача 456 не принадлежит ни одному проекту — укажите проект явно.`**

Проект определялся по задаче, но задача не входит ни в какой проект.

**`Ошибка: путь кэширования изображений для проекта 'Retail shelves' не настроен.`**

Добавьте `--images-dir` или `--no-images`, или настройте кэш: [setup-cache](setup-cache.md).

## Из Python

```python
cveta2.fetch_task(
    tasks: Sequence[int | str],
    output_dir: str | Path,
    *,
    project: int | str | None = None,
    completed_only: bool = False,
    images_dir: str | Path | None = None,
    download_images: bool = True,
    cache: Literal["use", "refresh", "off"] = "use",
    save_tasks: bool = False,
    connection: Connection | None = None,
) -> pandas.DataFrame
```

Записывает `dataset.csv` и `deleted.csv` и возвращает все выгруженные строки одной таблицей pandas со столбцами `cveta2.CSV_COLUMNS`. Без `project` проект берётся из первого числового ID в `tasks`. `cache` работает как у [`cveta2.fetch`](fetch.md#из-python).

Исключения (подклассы `cveta2.Cveta2Error`): `Не удалось определить проект: передайте project= или укажите задачи числовыми ID.`; задача не найдена или имя неоднозначно; каталог изображений не настроен; передан `images_dir` вместе с `download_images=False`; недопустимое значение `cache`; ошибки CVAT и S3.

```python
import cveta2

df = cveta2.fetch_task([456, 457], "output/", download_images=False)
print(len(df))
```

Как задать подключение — в [Python API](../python-api.md).
