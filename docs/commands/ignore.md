# cveta2 ignore

Ведёт список игнорируемых задач ([ignore list](../../GLOSSARY.md)) проекта: задачи (task) из этого списка `fetch` и `fetch-task` не выгружают. Нужна, когда задача сломана или ещё переделывается и не должна попасть в датасет.

## Примеры

Исключить задачу 456 из выгрузки и записать причину:

```bash
cveta2 ignore -p "Retail shelves" --add 456 -d "разметка переделывается"
```

Вернуть задачи в выгрузку (по ID или по имени):

```bash
cveta2 ignore -p "Retail shelves" --remove 456 shelves-batch-07
```

Показать игнорируемые задачи всех проектов (CVAT не нужен):

```bash
cveta2 ignore --list
```

## Синтаксис и аргументы

```text
cveta2 ignore [-h] [--project PROJECT] [--add TASK [TASK ...] | --remove TASK [TASK ...] | --list] [--description DESCRIPTION] [--silent]
```

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--project`, `-p` | выбор в терминале | ID или имя проекта CVAT. Можно указать организацию: `my-team/Retail shelves`. С `--list` не используется. |
| `--add TASK [TASK ...]` | | Добавить задачи в список. Каждая задача — ID или имя. |
| `--remove TASK [TASK ...]` | | Убрать задачи из списка. Каждая задача — ID или имя. |
| `--list` | выкл. | Напечатать списки всех проектов и выйти. Не подключается к CVAT. |
| `--description`, `-d` | пусто | Причина. Сохраняется только вместе с `--add`. |
| `--silent` | выкл. | Не печатать предупреждение о пропуске этой задачи при выгрузке. Действует только вместе с `--add`. |
| `-h`, `--help` | | Показать справку. |

`--add`, `--remove` и `--list` взаимоисключающие. Без них команда открывает меню в терминале.

## Как это работает

### Где хранится список

Список хранится в общей конфигурации ([global configuration](../../GLOSSARY.md)), в описании проекта ([project definition](../../GLOSSARY.md)), в поле `ignore`. Поэтому одно изменение видят все, у кого подключён тот же общий файл. Каждая запись содержит ID задачи, имя задачи на момент добавления, причину и признак `silent`:

```yaml
projects:
  shelves:
    id: 123
    name: Retail shelves
    ignore:
      - id: 456
        name: shelves-batch-07
        description: разметка переделывается
      - id: 457
        name: shelves-batch-08
        silent: true
```

Чтобы команда могла записать список, проект должен уже быть описан в разделе `projects` общей конфигурации. Ключи общей конфигурации описаны на странице [Конфигурация](../configuration.md).

### `--add`

1. Команда подключается к CVAT, находит проект и читает список его задач.
2. Каждое значение из `--add` ищется сначала как ID, затем как имя задачи (регистр не важен). Если хоть одно значение не найдено, команда завершается с ошибкой и ничего не записывает.
3. Каждая найденная задача добавляется с причиной из `--description` и признаком `--silent`. Задача, которая уже есть в списке, не меняется: её причина и `silent` остаются прежними. Чтобы их изменить, уберите задачу (`--remove`) и добавьте снова.
4. Список сохраняется в общий файл.

### `--remove`

1. Числовые значения, которые совпадают с ID в списке, убираются без поиска в CVAT. Так можно убрать запись о задаче, которой в CVAT уже нет.
2. Остальные значения ищутся среди задач проекта в CVAT, как при `--add`. Если хоть одно не найдено, команда завершается с ошибкой и ничего не убирает.
3. Для найденной задачи, которой нет в списке, печатается предупреждение.
4. Список сохраняется в общий файл.

### `--list`

Команда читает конфигурацию и печатает записи всех проектов. CVAT и `--project` не нужны.

### Меню

Без `--add`, `--remove` и `--list` команда печатает список проекта и показывает меню: «Добавить задачи в ignore-список», «Убрать задачи из ignore-списка» (если список не пуст) и «Готово».

- «Добавить» показывает задачи проекта, которых ещё нет в списке. Вы отмечаете нужные, затем вводите причину (можно оставить пустой) и отвечаете, включить ли `silent`. После этого команда печатает равносильную команду с `--add`.
- «Убрать» показывает записи списка. Вы отмечаете те, что нужно убрать.

Изменения из меню сохраняются в файл один раз, при выходе из меню.

### Что делает выгрузка с игнорируемой задачей

- [`fetch`](fetch.md) полностью пропускает задачу: её строк нет ни в одном из четырёх файлов полной выгрузки ([partition outputs](../../GLOSSARY.md)). Перед выгрузкой печатается предупреждение со списком пропущенных задач. Задачи с `silent` в нём не упоминаются, но тоже пропускаются.
- [`fetch-task`](fetch-task.md) тоже убирает игнорируемые задачи из списка задач проекта. Если указать игнорируемую задачу явно, команда завершится с ошибкой `Task not found`.

Сама задача в CVAT не меняется.

## Результат

Файлов, кроме общей конфигурации, команда не пишет. Примеры вывода:

```text
Задача 'shelves-batch-07' (id=456) добавлена в ignore-список проекта 'Retail shelves'
Задача 'shelves-batch-07' (id=456) уже в ignore-списке проекта 'Retail shelves' — описание и silent не изменены (используйте --remove, затем --add)
Задача 'shelves-batch-07' (id=456) удалена из ignore-списка проекта 'Retail shelves'
Задача 'shelves-batch-01' (id=450) не найдена в ignore-списке проекта 'Retail shelves'
```

Вывод `--list`:

```text
Проект 'Retail shelves' (2 задач):
  - 'shelves-batch-07' (id=456) — разметка переделывается
  - 'shelves-batch-08' (id=457) [silent]
Всего игнорируемых задач: 2
```

Пустые списки: `Ignore-списки пусты — нет игнорируемых задач ни в одном проекте`.

Предупреждение при выгрузке:

```text
Пропускаем 1 задач(а) из ignore-списка:
  - #456 'shelves-batch-07' (обновлена: 2026-01-15T10:00:00+00:00)
```

### Коды завершения

| Код | Когда |
|---|---|
| 0 | Успех. Повторное добавление и удаление задачи, которой нет в списке, тоже дают 0 (с предупреждением). |
| 1 | Задача или проект не найдены, проекта нет в общей конфигурации, нет общей конфигурации, нужно меню, а терминала нет. |
| 2 | Неверные аргументы, например `--add` вместе с `--remove`. |

## Интерактивный и неинтерактивный режим

В терминале команда без `--project` просит выбрать проект, а без `--add`, `--remove` и `--list` открывает меню.

При `CVETA2_NO_INTERACTIVE=true` укажите `--project` и одно из `--add`, `--remove`. `--list` работает без `--project`.

## Частые ошибки

```text
Task not found: '999'. Available tasks: 'shelves-batch-07' (id=456), ...
```

Значение не совпало ни с ID, ни с именем задачи проекта. Ничего не изменено. Возьмите ID или имя из списка в сообщении. Если задача в списке игнорируемых и её нет в CVAT, убирайте её по числовому ID.

```text
Имя задачи 'shelves-batch-07' неоднозначно: ... Укажите числовой ID задачи.
```

В проекте несколько задач с таким именем (регистр не учитывается). Укажите ID задачи.

```text
Unknown shared projects: ['Retail shelves']
```

Проекта нет в разделе `projects` общей конфигурации. Список не сохранён. Перед этой ошибкой команда всё равно печатает `... добавлена в ignore-список ...` — не верьте этой строке. Попросите того, кто ведёт общую конфигурацию, добавить описание проекта.

```text
Versioned personal configuration requires a shared project_config reference
```

В личной конфигурации не подключён общий файл. Подключите его через [`cveta2 setup --global-config`](setup.md).

```text
Interactive prompt required but CVETA2_NO_INTERACTIVE=true. Pass --project / -p to specify the project name.
```

Меню нельзя открыть без терминала. Эта подсказка появляется, даже когда `--project` уже указан. Добавьте `--add` или `--remove`.

```text
cveta2 ignore: error: argument --remove: not allowed with argument --add
```

За один запуск можно либо добавить, либо убрать задачи. Запустите команду дважды.

## Из Python

```python
cveta2.ignore(project, *, add=None, remove=None, description="", silent=False, connection=None) -> list[IgnoredTask]
```

Функция делает то же, что `--add` и `--remove`, и возвращает записи проекта после изменения. Без `add` и `remove` она только возвращает текущие записи. У записи есть поля `id`, `name`, `description`, `silent`. Функция всегда подключается к CVAT, чтобы найти проект.

Задача, которая не найдена, поднимает `cveta2.TaskNotFoundError`, проект — `cveta2.ProjectNotFoundError`. Оба — подклассы `cveta2.Cveta2Error`.

```python
import cveta2

entries = cveta2.ignore("Retail shelves", add=[456], description="разметка переделывается")
for entry in entries:
    print(entry.id, entry.name, entry.description, entry.silent)

cveta2.ignore("Retail shelves", remove=[456])
```

Параметр `connection` описан на странице [Python API](../python-api.md).
