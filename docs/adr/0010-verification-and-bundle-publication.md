# Keep verification evidence alongside an editable publication payload

## Verifying rows

CSV verification returns rejected rows and reasons under the selected profile. An output directory saves the report and broken rows. `--clean` also writes the clean CSV. Python can return a DataFrame validation result or the profile schema. Bundle preparation accepts cleanup by default. Blockers suppress its payload, while pending splits can wait until publication. [Verification rules](https://github.com/BuckanovNikita/cveta2/blob/8bf1e29ad4176e47419c87797b554315798051b3/tests/verification/test_validation.py) · [CLI behavior and exit status](https://github.com/BuckanovNikita/cveta2/blob/8bf1e29ad4176e47419c87797b554315798051b3/tests/bundle/test_interfaces.py)

## Preparing the bundle

Resolve publication settings from explicit choices, the dataset draft and parent metadata. Match classes by registry number across renames, canonicalize aliases and reject excluded classes. Prefill eligible empty split cells by matching parent images by name during bundle preparation. Archive the four fetch tables and retain broken-image diagnostics and the verification report. A successful preparation also writes the editable payload and task manifest. ## Publishing the current files

`upload-dataset` compares the recorded parent with the latest version, validates the edited files and rederives the task manifest. It queries the parent again before creating the new version. [Publication sequence](https://github.com/BuckanovNikita/cveta2/blob/8bf1e29ad4176e47419c87797b554315798051b3/cveta2/application/use_cases/dataset_bundle.py#L457-L481) The version contains `dataset.csv`, `dataset.yaml`, `tasks.yaml` and `sources.tar.gz`. Image roots point to external images. ## Inspecting a schema and verifying a DataFrame

`cveta2.schema_for(profile)` returns the Pandera schema for `cveta2` or `clearml-yolo`. Callers can use `.validate(frame, lazy=True)` to inspect column and cell errors. The schema preserves original values and extra columns. `cveta2.verify_dataframe(frame, profile=..., options=...)` also checks image groups, bounds and duplicates, plus image files when requested. The returned `ValidationResult` carries issues, clean and broken rows and their input positions. The caller’s DataFrame stays intact and the function writes no CSV or report.
