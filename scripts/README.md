# Скрипты (scripts/)

Два инструмента разработки, оба запускаются из корня репозитория через
`uv run python`. Остальная обвязка живёт там, где её используют:

| Что | Где |
|---|---|
| Проверка сообщения коммита | `.pre-commit-config.yaml` (готовый хук `conventional-pre-commit`) |
| Проверка владения эффектами (дополняет import-linter) | `tests/architecture_effects.py`, запускается из `tests/test_architecture.py` |
| Жизненный цикл живого прогона (up / stop / env; в pytest — фикстура сессии) | `tests/integration/lifecycle.py`, см. скилл `running-integration-tests` |
| Клонирование CVAT-проекта в S3 cloud storage | `tests/integration/clone_project_to_s3.py` |

## benchmark_fetch.py

Замеряет реальный конвейер `fetch` с контролируемой задержкой удалённых вызовов и локальными файлами.

**Назначение:** воспроизвести сравнение производительности из замеров фичи 001. Живые CVAT/S3 не нужны: удалённые вызовы — фикстуры внутри процесса с фиксированной искусственной задержкой, поэтому результаты сравнивают нагрузки, а не предсказывают пропускную способность сети.

```bash
uv run python -m scripts.benchmark_fetch --label working-tree --output after.json
```

## mutation.py

Мутационное тестирование (mutmut) только тех функций, которые меняет коммит.

**Назначение:** хук pre-commit `mutmut` запускает скрипт без аргументов. Скрипт
берёт изменённые строки из индекса (`git diff --cached` против `HEAD`;
`--base REV` сравнивает с merge-base от `REV`),
находит содержащие их функции и методы верхнего уровня `cveta2/` и запускает
mutmut только для их мутантов. Результат рекомендательный: выжившие мутанты
печатаются вместе с диффами, а хук проходит. Ошибка инструмента или чистого
прогона тестов хук роняет.

**Изоляция:** каждый прогон выгружает индекс (`git checkout-index`) во
временный каталог, сужает там `[tool.mutmut].only_mutate` до изменённых
файлов и запускает mutmut из venv репозитория. Кэш между прогонами не
переиспользуется, поэтому параллельные прогоны из других worktree или агентов
не мешают друг другу, а устаревший вердикт невозможен. Переменные живых
стендов (`CVAT_INTEGRATION_*`, `MINIO_*`, `CLEARML_*`) и `GIT_*` в mutmut не
передаются.

**Зависимости:** mutmut (dev-группа), git. cveta2 не импортируется.

**Примеры:**

```bash
# Изменения в индексе против HEAD (то же, что делает хук)
uv run python scripts/mutation.py

# Индекс против другой ревизии
uv run python scripts/mutation.py --base main

# Все функции файла целиком
uv run python scripts/mutation.py cveta2/domain/merge.py

# Сохранить рабочий каталог для mutmut show/browse и упасть при выживших
uv run python scripts/mutation.py --keep --strict
```

**Код возврата:** 0 — прогон завершён (выжившие только печатаются), менять
нечего или ни один юнит-тест не вызывает изменённые функции; 1 — то же при
`--strict`, если остались выжившие или непокрытые функции; 2 — ошибка
инструмента, конфигурации или чистого прогона тестов.

**Стоимость:** фиксированная часть — проход статистики mutmut (весь набор
юнит-тестов последовательно), плюс время самих мутантов.
