# Spec Kit archive

Spec Kit is temporarily disabled. Both host variants were moved intact from active
skill discovery into `codex/` and `claude/`. `manifest.json` records every original
path, archived path and SHA-256 digest. Preserve these files unchanged.

The existing `.specify/` and `specs/` trees are frozen historical sources. Their
instructions do not govern the new workflow. Explicit user authorization is required
to reactivate Spec Kit. Active engineering policy lives in
[engineering guidance](../../docs/agents/engineering.md); product contract migration
and authority are described in the [contract index](../../docs/agents/contracts.md).
